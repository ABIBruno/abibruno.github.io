# ABIdasmuss

VBWL-Abiturtrainer: alle 66 Aufgaben der sächsischen VBWL-Abiturprüfungen (LK, 2017–2024), sortiert nach Lernbereichen LB1–LB6, mit ausführlichen Lösungen.

Die Inhalte in `data/` sind mit AES-256-GCM verschlüsselt (Schlüssel per PBKDF2 aus dem Passwort) und werden erst im Browser nach Eingabe des Passworts entschlüsselt.
